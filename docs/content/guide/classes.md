# Classes and attendance

**Classes** shows the classes you are involved with — as class teacher, or as the teacher of a subject in them. It is not the whole school unless you are an administrator.

## Inside a class

Opening a class gives you its roster and its subjects, and the tabs for everything else: **Work**, **Attendance**, **Reports** and the **Class report**.

### Students

Enrol students into the class from the school roster, one at a time or in bulk.

A student can be enrolled in more than one class — useful for sets and option groups. The only thing prevented is enrolling the same student into the same class twice, which the app refuses with *"Student is already enrolled in this class."*

Removing a student from a class does not delete them from the school, and does not erase marks they already earned.

### Subjects and teachers

A class takes a set of subjects, and each subject has a teacher. Assign both here.

This assignment is what gives a subject teacher access. Until a subject has a teacher, nobody but the class teacher can set work for it.

Students can also be assigned individual subjects, for schools where not everyone in a class takes everything. Where that applies, a student's report shows only the subjects they actually take.

> **Class teacher or subject teacher?** The class teacher owns the roster, the report books and anything committing the class as a whole. A subject teacher sets and marks work for their own subject and can read the class's reports. Both see the class; they can do different things inside it.

## Attendance

The **Attendance** tab marks a register for a date. Each student is **Present**, **Absent** or **Late**.

Pick the date first — it defaults to today, and the commonest mistake is marking yesterday's register onto today. Marks save as you go.

Attendance feeds two places: the student's own portal, and the attendance figures printed on a report card. A term's register being incomplete shows up there as a lower total, so catch up on missed days before generating report cards.

Editing an old register is allowed and takes effect immediately; there is no lock-out date.

## What students see

A student sees their own attendance in their portal — the same statuses, on the same dates, as soon as you save. There is no separate publish step, so correct mistakes promptly rather than at the end of term.
